Voronoi board map generator

Procedural board-map draft: Voronoi land tiles, randomized sea corners, optional central lake, balanced clustered biomes, wobbly borders, objects, and magic/mine/cave symbols.

Tile shape

Higher chonkiness spaces tile centers more evenly, making tiles rounder and easier to place pieces on.

Low spread = scattered biomes. High spread = biomes gather into larger regions.

Water size

Biome proportions

These are relative weights, not strict percentages. Equal values give roughly equal biome amounts. Set a biome to 0 to almost remove it.

Biome texture zoom

Higher zoom means each tile uses a smaller crop from the biome image, so the pattern appears larger. Lower zoom shows more of the source image inside each tile.

Forest / mountain object layers

Forest tiles now start as hill tiles and draw tree sprites from src/assets/forests/pine or src/assets/forests/normal. Mountain tiles do the same with src/assets/mountains. Bigger objects automatically mean lower density.

Feature symbols

Count controls how many icons are placed. Spread controls whether each icon type scatters or clusters.

Water layout

When randomization is on, the number of checked corner boxes below decides how many sea corners are chosen. If none are checked, it defaults to 2 random sea corners.

The center lake reserves one larger water tile, roughly 1.3× the size of a typical tile.
